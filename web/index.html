How it fits

静态壳，加上可选的树莓派

页面不自带望远镜。它只在浏览器里探测有没有 Telbot 的 HTTP 服务。探测失败就停在浏览模式。

  1. 打开页面

    GitHub Pages、本机静态服务器，或树莓派上的 telbot serve，看到的是同一套文件。

  2. 探测 GET /health

    同源页面优先请求相对路径 /health。静态托管则继续尝试已保存地址、隧道、局域网名和本机端口。

  3. 失败就只浏览

    状态保持「设备未连接」。控制区整组停用，避免在没有后端时发出指向或曝光。

  4. 成功才控制

    文字走 /text，问答走 /chat，拍摄、计划和参数走各自的 API。默认 execute=false。

A. 树莓派同源

浏览器打开 http://主机:8765/。页面和 API 同一来源，控制台直接使用相对路径。

B. GitHub Pages

介绍一直在线。要遥控望远镜，在连接面板填写树莓派或 https 隧道地址，或让自动探测命中本机与 telbot.local。

自动探测顺序

  1. 地址栏参数 ?api=，或连接面板里填写的地址
  2. 与当前页面同源的 /health
  3. 勾选「记住此地址」后保存的 API
  4. 曾经保存过的 https 隧道
  5. http://telbot.local:8765
  6. http://127.0.0.1:8765

填写了地址仍会按上面的顺序继续找；若最终用了别的地址，面板会写明。把 ?api=same 设上时，只检测同源。

Safety

默认不动设备

干跑

真机执行默认关闭。关闭时，指向、曝光和计划请求都带着 execute=false，用于核对意图。

再次确认

打开真机执行本身需要确认。之后每一次会真实控制设备的操作，都会再问一次。

参数会立刻写入

保存参数调用 PATCH /config/env，不看干跑开关。它会写回树莓派上的 .env，所以保存前单独确认。

不要暴露到公网

跨域头只让浏览器能调用接口，不是登录。隧道链接不要发给不信任的人，树莓派也不要直接对公网开放。

现场

真机前确认镜筒周围无障碍、线缆不受拉扯，并且没有 Ekos 等软件同时控制同一套设备。

HTTPS 页面的限制

GitHub Pages 是 https。浏览器会拦截它去请求 http://127.0.0.1 或 http://telbot.local。远程控制需要 https 隧道，或改用树莓派上的 http 页面。

Tour

界面导览

下面这些区域在未连接时也能看。控制按钮会是灰色的，直到健康检查成功。

  1. 顶栏状态

    「设备未连接」或「设备已连接」，旁边是浏览、干跑或真机。这是整页的总开关说明，不是装饰。

  2. 连接面板

    填写 API 根地址，勾选是否记住，然后按「重新检测」。成功后这里摘要版本、INDI、赤道仪、相机、电调和滤镜轮。

  3. 安全条

    真机开关和急停放在所有控制页的上面。未连接时它们和拍摄、计划一起停用。

  4. 对话

    「什么是 INDI」这类问题走 /chat。 「指向木星」走 /text。语音在连接后才发送。

  5. 拍摄、设备、计划、参数

    单张和叠图、USB 与电调、凌星计划、白名单里的 TELBOT_* 参数。读取和执行都要后端在线。
